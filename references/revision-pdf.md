# Revisión final del brochure PDF

Usa esta lista cuando el brochure incluya páginas diseñadas, enlaces o códigos QR. Ajusta el alcance al formato y a lo que el usuario pidió.

## Composición

- Renderiza todas las páginas a imagen e inspecciónalas en el tamaño aproximado de lectura final. Revisa portada e interiores juntos: misma familia tipográfica, pesos realmente distintos, colores de marca, ritmo de márgenes y jerarquía de títulos.
- Comprueba que la portada represente la empresa y sus servicios prioritarios. Una imagen conceptual no debe parecer una fotografía de una obra ejecutada. Los elementos tomados de una referencia sirven para composición, no para copiar promociones o textos de ejemplo.
- Revisa recortes de fotos, superposición de texto, contraste, iconos deformados, espacio en blanco, viudas y texto cortado. Evita que una página de servicio secundario compita visualmente con la principal si el usuario pidió otra jerarquía.
- Comprueba las fuentes incrustadas en el PDF. Si regular y negrita parecen iguales, revisa los nombres internos de los archivos de fuente, no solo sus nombres de archivo.

## Datos e interacción

- Compara nombre público, teléfono visible, correo, dominio, dirección y perfiles con las fuentes o confirmaciones del usuario. Conserva literalmente la dirección confirmada y distingue cobertura de sedes reales.
- Comprueba que el número visible respete el formato pedido. El enlace `wa.me` usa dígitos internacionales, aunque el indicativo no se muestre en el impreso.
- Usa iconos de marca obtenidos de una fuente fiable, conserva sus proporciones y alinea su tamaño óptico. En un brochure, colócalos discretamente y vincula el área pulsable al perfil exacto. No sustituyas el logotipo de una red por una aproximación dibujada.
- Si aparece una dirección, usa un icono de ubicación reconocible y verifica que el enlace de Maps abra ese lugar. El icono de sitio web debe apuntar al dominio correcto.
- Enumera las anotaciones de enlace del PDF exportado. Escanea cada QR desde una imagen de la página final, no solo desde el dato utilizado para generarlo. Verifica que WhatsApp y web lleven a destinos distintos cuando ambos QR estén presentes.

## Entrega

- Mantén un peso práctico para el canal de distribución sin sacrificar legibilidad. Usa derivados de imagen apropiados para la página cuando los originales hagan el PDF excesivamente pesado.
- Deja identificado el PDF final. Conserva el archivo editable o generador cuando exista. Elimina borradores solo si el usuario lo pidió.
